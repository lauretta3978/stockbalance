## 2. Core Reconciliation Logic
1. **Data Ingestion:** Load the AutoCount inventory sheet and OpenCart product/stock sheet.
2. **Key Matching:** Establish **ISBN** as the primary unique identifier key across both platforms.
3. **VLOOKUP / Quantity Mapping:** 
   - Look up each product's ISBN from the AutoCount inventory record.
   - Match it against the corresponding OpenCart product entry.
   - Extract the updated stock balance quantity from AutoCount.
4. **Target Update:** Update the quantity field within the target export file (`HD_Export-Products-2026-10-14-170223_FINAL`) ensuring zero discrepancies or missing keys.

import pandas as pd

def update_stock_balance(autocount_csv, opencart_csv, target_csv, output_csv):
    # Load datasets
    df_autocount = pd.read_csv(autocount_csv)
    df_opencart = pd.read_csv(opencart_csv)
    df_target = pd.read_csv(target_csv)
    
    # Standardize ISBN columns for clean matching
    df_autocount['ISBN'] = df_autocount['ISBN'].astype(str).str.strip()
    df_target['ISBN'] = df_target['ISBN'].astype(str).str.strip()
    
    # Create mapping dictionary from AutoCount (ISBN -> Quantity)
    stock_mapping = dict(zip(df_autocount['ISBN'], df_autocount['Balance Quantity']))
    
    # Update target export file quantities based on ISBN lookup
    df_target['Quantity'] = df_target['ISBN'].map(stock_mapping).fillna(df_target['Quantity'])
    
    # Save final reconciled file
    df_target.to_csv(output_csv, index=False)
    print(f"Successfully updated stock balance. Saved to {output_csv}")
